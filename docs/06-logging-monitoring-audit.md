# Logging, Monitoring, and Auditability

## Telemetry Sources
- Entra ID Sign-in Logs
- Entra ID Audit Logs
- Identity Protection risk reports

## Monitored Events
- MFA challenges and outcomes
- Conditional Access allow/deny decisions
- Privileged role activations and deactivations
- Policy and configuration changes

## Audit Readiness
- Centralized identity telemetry
- Traceable administrative actions
- Evidence suitable for security reviews and compliance audits
