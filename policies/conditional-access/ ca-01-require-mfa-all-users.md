# CA-01 | Require MFA – All Users

## Objective
Ensure all users authenticate using multi-factor authentication.

## Scope
- Users: All users
- Exclusions: breakglass@cloud.goddyotuwho.com

## Conditions
- Any location
- Any device
- Any application

## Grant Controls
- Require multi-factor authentication

## Rationale
MFA significantly reduces the risk of credential compromise and is a foundational Zero Trust control.
