# CA-06 | Require Password Change – High User Risk

## Objective
Force remediation when a user account is assessed as high risk.

## Scope
- Users: All users
- Exclusions: breakglass@cloud.goddyotuwho.com

## Conditions
- User risk: High

## Grant Controls
- Require password change

## Rationale
Compromised user accounts require immediate remediation to restore trust.
