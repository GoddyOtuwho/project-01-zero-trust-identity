# CA-03 | Require MFA – Admin Portals

## Objective
Protect privileged access to administrative portals.

## Scope
- Users: Directory roles
- Exclusions: breakglass@cloud.goddyotuwho.com

## Applications
- Azure Management
- Microsoft Entra admin center

## Grant Controls
- Require multi-factor authentication

## Rationale
Administrative portals represent high-value targets and require stronger authentication.
